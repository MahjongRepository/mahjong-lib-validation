## テストの共通処理の整理（2026-11-04）

共有処理を `tests/conftest.py` の factory fixture に移し、
`tests/__init__.py` を追加した。`helpers.py` と相対 import、INP001 の除外を削除した。
pytest の `consider_namespace_packages` を有効にし、全メンバーを一緒に収集した際の
同名 `tests.conftest` の衝突を解消する。
変更前後とも全体 317 件成功、既存の実 symlink 1 件スキップ。
Ruff の lint・format と ty の型検査も成功した。
実行時コード・配布設定の振る舞いは変更しない。

## 初期実装の確認記録（2026-11-03）

- Python 3.15.2、mahjong 2.1.0 を使用。依存範囲は `>=2.1.0,<2.2`。
- validator の追加テスト 67 件、全体 317 件成功、既存の実 symlink 1 件スキップ。
  Ruff の lint・format と ty の型検査も成功した。
- corpus と validator の wheel をビルドし、クリーンな 3.15 環境へ
  corpus・mahjong・validator だけを導入。API・CLI の得点検証、版表示、
  不正入力の終了コードと結果非公開を確認した。
- Red は API 未実装、役名を比較しない偽陽性、三麻・副露・状況フラグの未反映、
  比較除外の未適用、不明入力の補完、計算例外による中断、
  上限以降の破損時に結果ディレクトリが残る問題、CLI の失敗処理、
  重複役の偽陽性、複数ロンの個別配分の誤比較などで確認した。
- 小さな四麻ロン・副露・国士、三麻ツモ・抜き北の XML fixture から、
  converter → corpus → mahjong → 結果保存の結合経路を確認した。
  構造確認用の合成 converter fixture 全体を得点の正解データとしては使わない。
- 件数上限以降のハッシュ・件数不一致、絞込後の重複 ID、空選択、全件スキップ・
  未対応、逐次計算、中断・書込失敗時の非公開、既存結果の保護を確認した。

実装中に確定した制約:

- ライブラリは Dora に抜きドラを含める。役比較では両者を合算し、
  赤ドラ・裏ドラとの補償的な誤りは不一致にする。合算方針は結果にも保存する。
- 個別配分が入力にない複数ロンでは、特定できる範囲でボーナス・個別支払いを
  unsupported とする。期待値から計算入力を補正しない。
- イベント全体の点数移動と雀魂ルールは未対応。項目とケース全体の未対応を
  区別して報告する。詳細は [API・結果形式](validator-results.md) を参照する。
- Tachyon 等の計測・プロファイルの実証は後続段階で行う。
